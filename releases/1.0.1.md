- **Downloads links survive other apps' order updates.** When another app saved the order at the same moment, the order could lose its downloads link and buyers saw "This link isn't valid". The link's token is now kept with the app's own access records.
- **Clearer bucket setup.** The uploader runs on its own address, not the store's. Setup now says to allow that address in the bucket's CORS rule, and the uploader shows the exact address when the rule is missing.
